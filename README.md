# Rock Paper Scissors

Implementação do jogo clássico "Pedra, Papel e Tesoura" desenvolvida como parte da trilha Foundations do The Odin Project, primeiro proposto com uma [**versão console**](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) e posteriormente evoluída para uma [**interface gráfica completa**](https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors#adding-a-ui-to-rock-paper-scissors).

## Evolução do Projeto

### 🚀 [Implementação Inicial](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors)
Primeira versão focada em lógica de programação básica:
- Jogo funcionando apenas via console
- Estruturas condicionais e funções JavaScript
- Interação através de `prompt()` e `console.log()`
- Fundamentos da lógica do jogo

### 🔄 [Revisitando o Projeto](https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors#adding-a-ui-to-rock-paper-scissors)  
Evolução para interface gráfica com Git branching:
- Criação de branch `rps-ui` para nova funcionalidade
- Substituição do console por interface visual
- Adição de botões interativos e display de resultados

## Objetivo do Projeto

O objetivo principal era praticar:
- Lógica de programação básica
- Estruturas condicionais (if/else)
- Funções JavaScript
- Geração de números aleatórios
- Interação básica com o usuário
- Loops e contadores

## O que é?

Um jogo de Pedra, Papel e Tesoura que evoluiu de uma versão simples no console para uma aplicação web interativa. O projeto demonstra o ciclo de desenvolvimento com Git branching, onde novas funcionalidades são implementadas em branches separadas e posteriormente integradas.

### Funcionalidades
- **Interface Gráfica**: Botões interativos para seleção das jogadas
- **Display Visual**: Resultados e pontuação exibidos na tela
- **Lógica Completa**: Sistema de pontuação até 5 vitórias

### Mecânica do Jogo
- O computador escolhe aleatoriamente sua jogada
- O jogador clica em um dos três botões (Pedra, Papel, Tesoura)
- O sistema determina o vencedor da rodada
- Primeiro a alcançar 5 vitórias ganha o jogo

## Como usar

1. Abra o arquivo `index.html` em seu navegador
2. Clique nos botões para fazer sua escolha
3. Acompanhe a pontuação na tela
4. Jogue até que alguém alcance 5 vitórias

## Regras do Jogo

- **Pedra** vence **Tesoura**
- **Tesoura** vence **Papel**  
- **Papel** vence **Pedra**
- Mesma escolha = Empate

## Conceitos Aprendidos

- **Lógica de Programação**: Estruturas condicionais, loops, funções
- **Manipulação do DOM**: Event listeners, alteração de conteúdo
- **Git Workflow**: Branching, merge, e versionamento de funcionalidades
- **Refatoração de Código**: Adaptação do código existente para novas funcionalidades
