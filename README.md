# Rock Paper Scissors

Implementation of the classic Rock Paper Scissors game developed as part of the [Foundations path of The Odin Project](https://www.theodinproject.com/paths/foundations/courses/foundations), first proposed as a [**console version**](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) and later evolved into a [**complete graphical interface**](https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors#adding-a-ui-to-rock-paper-scissors).

## Project Evolution

### [Initial Implementation](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors)
First version focused on basic programming logic:
- Game running only in the console
- Conditional structures and JavaScript functions
- Interaction through `prompt()` and `console.log()`
- Fundamentals of game logic

### [Revisiting the Project](https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors#adding-a-ui-to-rock-paper-scissors)  
Evolution to a graphical interface with Git branching:
- Creation of branch `rps-ui` for the new functionality
- Replacement of console output with a visual interface
- Addition of interactive buttons and result display

## Project Objective

The main objective was to practice:
- Basic programming logic
- Conditional structures (if/else)
- JavaScript functions
- Random number generation
- Basic user interaction
- Loops and counters

## What is it?

A Rock Paper Scissors game that evolved from a simple console version into an interactive web application. The project demonstrates a development cycle with Git branching, where new features are implemented in separate branches and later integrated.

### Features
- **Graphical Interface**: Interactive buttons for selecting moves
- **Visual Display**: Results and score shown on screen
- **Complete Logic**: Score system up to 5 wins

### Game Mechanics
- The computer randomly chooses its move
- The player clicks one of the three buttons (Rock, Paper, Scissors)
- The system determines the winner of the round
- The first to reach 5 wins is the game winner

## How to use

1. Open the `index.html` file in your browser
2. Click the buttons to make your choice
3. Follow the score on screen
4. Play until someone reaches 5 wins

## Game Rules

- **Rock** beats **Scissors**
- **Scissors** beats **Paper**  
- **Paper** beats **Rock**
- Same choice = Draw

- **Git Workflow**: Branching, merge, and feature versioning
- **Code Refactoring**: Adapting existing code to new functionality
